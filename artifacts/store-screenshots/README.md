# Store listing screenshots

Three native Android captures at 1080 x 1920, 24-bit RGB PNG with no alpha:

- 01-desert.png: Wave 86 desert, Stormblade lightning/crescent with Cannon artillery and Basketball Player support.
- 02-space.png: Wave 46 space, Gundam beam sword with Mech missile explosions and Space Marine support.
- 03-lava.png: Wave 36 lava, Dark Mage fire blast with Skeleton King green sword/skulls and Barbarian frontline.

These are staged combat snapshots generated by the real simulation and displayed through the existing native BattleScreen/Battlefield and deployment UI. No AI-generated or painted-in units, scenery, attacks, or UI were added. Capture entry never reads or writes player progress. The normal app entry was restored afterward; the existing Play upload bundle was not changed.

warling-rush-store-screenshots.zip contains exactly these three full-resolution PNG files. preview.png is a contact sheet for reviewing the set, not an upload screenshot.
